# Kronland

Ein mittelalterliches Aufbau- und Eroberungsspiel: Burgen bauen, ein Dorf mit Wirtschaft aufziehen, das Land erkunden und die anderen Königreiche besiegen – allein oder zu zweit im selben WLAN.

Hier liegen nur die **fertigen Spieldateien** und ihre **Updates** (kein Quellcode).

## Herunterladen

Unter **[Releases](../../releases/latest)** bei der neuesten Version:

- **Windows:** `Kronland-Windows.zip` entpacken und `Kronland.exe` starten. Warnt Windows („Unbekannter Herausgeber“): „Weitere Informationen“ → „Trotzdem ausführen“.
- **Mac:** `Kronland-Mac.zip` entpacken und `Kronland.app` öffnen (beim ersten Mal: Rechtsklick → „Öffnen“).

## Updates

Kronland sucht beim Start selbst nach einer neuen Version, lädt sie und startet neu. Spielstände und Einstellungen bleiben erhalten.

## Mehrspieler

Ein Rechner klickt im Startmenü auf „Runde eröffnen“, der andere auf „Runde suchen“. Beide brauchen dieselbe Version – dafür sorgen die automatischen Updates.
